# Nimbus

Site para consultar o clima atual por cidade ou localidade: condição do clima,
temperatura, probabilidade de chuva e sensação térmica.

## Tecnologias
- Front-end: HTML, CSS e JavaScript
- Back-end: Node.js com Express
- Dados: API da Open-Meteo 

## Como rodar
1. Instale o Node.js
2. No terminal, dentro da pasta do projeto: npm install
3. Depois: node src/server.js
4. Abra http://localhost:3000

## Créditos
Weather data by Open-Meteo.com
